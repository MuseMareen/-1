Программа собирает и добавляет в список "par" различные характеристики ОС, такие как:
- Название ОС (Windows, Linux или macOS(Darwin));
- Версия;
- Релиз ОС;
- Сетевое имя ПК;
- Модель CPU;
- Количество ядер процессора;
- Разрядность процессора.
Затем полученные данные сохраняет в файле "information.json".
В программе использованы 3 стандартных модуля Python: os, platform и json.
Os - библиотека, предназначенная для работы с операционной системе. В коде используется функция os.cpu_count, которая выводит целое число ядер процессора.
PLatform так же необходим для получения информации об операционной системе ( + текущей версии самого интерпретатора python). В программе использованы функции platform.system(), platform.version(), platform.release(), platform.processor(), platform.processor(), platform.architecture() (выводит кортеж, в файл записано только первый элемент - разрядность).
json - модуль для кодирования и декодирования данных в  текстовом формате JSON. json.dump() - записывает объект в файл.
